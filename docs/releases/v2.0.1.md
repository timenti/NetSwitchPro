NetSwitch Pro 2.0.1 добавляет переключение между двумя сохранёнными Wi‑Fi-сетями на одном адаптере. Программа показывает текущее подключение и подписывает кнопку именем следующей сети.

## Что нового

- **Пара Wi‑Fi-сетей.** Выберите две сети один раз и переключайтесь между ними одной кнопкой. Настройка сохраняется в профиле Windows.
- **Вкладка адаптеров.** У каждого интерфейса видны состояние, тип и IPv4 при наличии. Режим просмотра и запрос прав администратора обозначены в отдельном блоке.
- **Переключение адаптеров.** Если первый адаптер подключён, программа включает второй и ждёт подтверждения связи. При сбое результат восстановления появляется в журнале.
- **Новый интерфейс.** Графитовая и светлая темы, выровненные строки в списках, белая кнопка сохранения настроек и квадратная иконка с символом сетевого порта.
- **Запуск.** У переносимой сборки x64 встроена среда выполнения. Обычный старт и переключение Wi‑Fi работают без повышения прав.

## Как настроить две Wi‑Fi-сети

1. Подключитесь к каждой сети через меню Wi‑Fi Windows, чтобы сохранить оба профиля.
2. Запустите **NetSwitch Pro**. На вкладке **Сети Wi‑Fi** выберите адаптер, **Сеть A** и **Сеть B**.
3. Нажмите кнопку с именем целевой сети. После подключения она предложит вторую сеть из пары.

Если подключение сейчас вне выбранной пары, первым вариантом будет **Сеть A**. Успех или ошибку можно посмотреть в **Журнале**.
