NetSwitch Pro 2.0.5 увеличивает и упрощает рисунок значка в области уведомлений Windows.

- Для трея используется отдельная иконка с крупным символом сетевого порта. Она загружается в размере, который Windows сообщает для маленьких значков.
- Вращение, галочка и крестик тоже стали крупнее и используют тот же размер.
