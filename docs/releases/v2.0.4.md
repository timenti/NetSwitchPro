NetSwitch Pro 2.0.4 добавляет переключение пары одним кликом по значку и запуск в трее после входа в Windows.

- **Левый клик** по значку переключает сохранённую пару. Значок вращается во время подключения, показывает галочку при успехе или крестик при сбое и возвращается к обычному виду.
- **Правый клик** открывает компактную панель. Сверху видна активная сеть и кнопка **«Переключить на …»**. Ниже можно выбрать один из сохранённых профилей.
- **Настройки → Запускать вместе с Windows в трее** включает и выключает автозапуск для текущего пользователя. При входе главное окно скрыто. Обычный запуск из «Пуска» открывает его.
