## Ethernet и Wi-Fi

- NetSwitch Pro различает выключенный адаптер и включённый адаптер без подключения.
- Когда оба адаптера включены, переключение учитывает активный маршрут Windows. При переходе на Wi-Fi программа отключает Ethernet после подтверждения подключения.
- На вкладке **Адаптеры** выбор беспроводного адаптера сразу открывает список его сохранённых Wi-Fi-сетей. Вариант **Автоматически** оставляет выбор сети Windows.
- Если Wi-Fi не подключается при активном Ethernet, NetSwitch Pro может отключить Ethernet и повторить попытку. При неудаче программа восстановит Ethernet и покажет результат в журнале.

Основные кнопки и переключатель автозапуска теперь белые. Кнопка смены сети в главном окне стала компактнее. В трее кнопка со стрелками расположена рядом с текущей сетью. Зелёная точка обозначает подключённую сеть, красная — остальные. Список всех сетей открывается небольшой кнопкой. Заголовок окна использует цвет фона программы, а в тёмной теме название и символ стали светлее.

### Как настроить

1. Подключитесь к нужной Wi-Fi-сети через Windows, чтобы сохранить её профиль.
2. В NetSwitch Pro откройте **Адаптеры**, выберите Ethernet и Wi-Fi и нажмите **Запросить права**.
3. Откройте **Беспроводная сеть** в списке адаптеров, выберите профиль, например `Germany Network`, и нажмите **Переключить на …**.

**Скачать:** `NetSwitchPro-2.0.6.exe` для Windows x64. Приложение можно запустить прямо из загруженного файла.
