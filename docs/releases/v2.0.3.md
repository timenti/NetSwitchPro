NetSwitch Pro 2.0.3 добавляет быстрое переключение Wi-Fi из области уведомлений Windows.

- Нажмите значок NetSwitch Pro возле часов или под стрелкой **^**. В компактной панели видны активная сеть и сохранённая пара.
- Нажмите на другую сеть из пары, чтобы подключиться. Через **Все сохранённые сети** можно выбрать любой профиль выбранного адаптера.
- Крестик главного окна скрывает его в область уведомлений. Пункты **Открыть NetSwitch Pro** и **Выход** возвращают окно или завершают работу.
- Повторный запуск из меню «Пуск» открывает уже запущенный NetSwitch Pro.
